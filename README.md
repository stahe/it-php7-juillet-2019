# Introduzione a PHP 7: script da console e servizi web

📘 **Accedi alla documentazione del corso:** [https://stahe.github.io/it-php7-juillet-2019/](https://stahe.github.io/it-php7-juillet-2019/)

---

Questo progetto offre una raccolta di script da console in PHP 7 che illustrano vari aspetti del linguaggio e del suo ecosistema.

## Contenuti del repository

Gli esempi trattano i seguenti argomenti:
- **Strutture del linguaggio**
- **Accesso ai file**
- **Accesso al database**
- **Accesso a Internet**

## Approccio web

La programmazione web viene qui affrontata dal punto di vista dei **servizi web**. In questo contesto, definiamo un "servizio web" come qualsiasi applicazione che produce testo semplice (server di dati), al contrario dei server di pagine web che generano un mix di HTML, CSS e JavaScript.

### Concetti chiave trattati
Il progetto esplora i concetti web fondamentali utilizzati nella programmazione tradizionale:
- Protocollo HTTP
- Formati di risposta JSON o XML
- Gestione delle sessioni
- Autenticazione
