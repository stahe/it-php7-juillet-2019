    22. Esercizio pratico – versione 11

    È ancora frequente che i servizi web inviino la loro risposta sotto forma di un flusso XML anziché di un flusso jSON:

    • il flusso jSON è più snello, ma per comprenderlo occorre una guida all’uso;
    • il flusso XML è più dettagliato ma è autodocumentato. La sua comprensione è immediata;

    Modifichiamo la versione 11 client/server in modo che il server invii d'ora in poi un flusso XML come risposta ai propri client:

    22.1. Il server

    Questa architettura sarà implementata dai seguenti script:

    22.1.1. La classe [Utilitaires]

    Riprendiamo la classe [Utilitaires] utilizzata a partire dalla versione 03 (cfr. paragrafo "link"):

    
<?php

// spazio dei nomi
namespace Application;

// una classe di funzioni di utilità
abstract class Utilitaires {

  public static function cutNewLinechar(string $ligne): string {
    …
  }


  // da https://stackoverflow.com/questions/1397036/how-to-convert-array-to-simplexml
  public static function getXmlForArrayOfAttributes(array $arrayOfAttributes,
    \SimpleXmlElement &$node): void {
    // si analizzano gli attributi dell'array
    foreach ($arrayOfAttributes as $attribute => $value) {
      // L'attributo è numerico?
      if (is_numeric($attribute)) {
        // caso dell'indice dell'array (ma anche altri casi)
        $attribute = 'i' . $attribute;
      }
      // $value è un array?
      if (is_array($value)) {
        // Esploreremo a nostra volta l'array [$value]
        // si aggiunge un nodo al grafo XML
        $subnode = $node->addChild($attribute);
        // chiamata ricorsiva per esplorare l'array [$value]
        Utilitaires::getXmlForArrayOfAttributes($value, $subnode);
      } else {
        // si aggiunge il nodo al grafo XML
        $node->addChild("$attribute", htmlspecialchars("$value"));
      }
    }
  }
}

    Commenti

    • righe 14-36: introduciamo il metodo statico [getXmlForArrayOfAttributes] che restituisce la stringa XML di un array [arrayOfAttributes] passato come parametro. Il secondo parametro è il riferimento a un nodo di un grafo XML, di tipo [SimpleXmlElement]. Dopo l'esecuzione, questo nodo contiene il grafo XML dell'array [arrayOfAttributes];

    Scriviamo il test [testXml.php] seguente:

// funzione di invio della risposta HTTP al cliente
function sendResponse(Response $response, array $result, int $statusCode,
  array $headers, Logger $logger = NULL, \Predis\Client $predisClient = NULL) {
  // $response: risposta HTTP
  // $result: tabella dei risultati
  // $statusCode: stato HTTP della risposta
  // $headers: intestazioni HTTP da inserire nella risposta
  // $logger: il logger dell'applicazione
  // $predisClient: un client [predis]
  //
  // stato HTTTP
  $response->setStatusCode($statusCode);
  // corpo XML
  $node = new \SimpleXMLElement("<?xml version='1.0' encoding='UTF-8'?><réponse></réponse>");
  Utilitaires::getXmlForArrayOfAttributes($result, $node);
  $response->setContent($node->asXML());
  // intestazioni
  $response->headers->add($headers);
  // invio
  $response->send();
  // registro
  if ($logger != NULL) {
    // log in jSON
    $log = \json_encode(["réponse" => $result], JSON_UNESCAPED_UNICODE);
    $logger->write("$log\n");
    $logger->close();
  }
  // chiusura della connessione [redis]
  if ($predisClient != NULL) {
    $predisClient->disconnect();
  }
}

    22.2.1. Il livello [dao]

    Il client [ClientDao.php] (riga 13 sopra) viene modificato per tenere conto del nuovo formato della risposta. Per elaborarla si utilizza [simpleXML]:

    
<?php

namespace Application;

// dipendenze
use \Symfony\Component\HttpClient\HttpClient;

class ClientDao implements InterfaceClientDao {
  // utilizzo di un Trait
  use TraitDao;
  // attributi
  private $urlServer;
  private $user;
  private $sessionCookie;

  // costruttore
  public function __construct(string $urlServer, array $user) {
    $this->urlServer = $urlServer;
    $this->user = $user;
  }

  // calcolo dell'imposta
  public function calculerImpot(string $marié, int $enfants, int $salaire): array {
    …
    // si recupera la risposta XML
    $réponse = $response->getContent(false);
    $xml = new \SimpleXMLElement($réponse);
    // log
    // stampa "$réponse\n";
    // si recupera lo stato della risposta
    $statusCode = $response->getStatusCode();
    // errore?
    if ($statusCode !== 200) {
      // si verifica un errore - si genera un'eccezione
      $message = \json_encode(["statut HTTP" => $statusCode, "réponse" => $xml], JSON_UNESCAPED_UNICODE);
      throw new ExceptionImpots($message);
    }
    if (!$this->sessionCookie) {
      // si recupera il cookie di sessione
      $headers = $response->getHeaders();
      if (isset($headers["set-cookie"])) {
        // cookie di sessione?
        foreach ($headers["set-cookie"] as $cookie) {
          $match = [];
          $match = preg_match("/^PHPSESSID=(.+?);/", $cookie, $champs);
          if ($match) {
            $this->sessionCookie = "PHPSESSID=" . $champs[1];
          }
        }
      }
    }
    // si restituisce la risposta sotto forma di array
    return \json_decode(\json_encode($xml, JSON_UNESCAPED_UNICODE), true);
  }

}

    Commenti

    • righe 26-27: viene letta la risposta del server. Si tratta di un documento XML [<réponse>…</réponse>]. Viene creato un oggetto [SimpleXMLElement] a partire dal documento XML ricevuto;
    • righe 33-37: in caso di errore, il messaggio dell’eccezione sarà la stringa jSON della risposta del server anziché la stringa XML raccolta. Infatti, la stringa jSON è più concisa;
    • riga 53: si restituisce la tabella dei risultati in due fasi:
      • l’oggetto [$xml] di tipo [\SimpleXMLElement] viene convertito in jSON;
      • la stringa jSON ottenuta viene trasformata in un array associativo. Questo è il risultato da restituire;
