    La classe [Utilitaires] raggruppa metodi utili alla gestione dei file di testo (in questo caso un unico metodo):

    
<?php

// spazio dei nomi
namespace Application;

// una classe di funzioni di utilità
abstract class Utilitaires {

  public static function cutNewLinechar(string $ligne): string {
    // si rimuove il carattere di fine riga da $ligne se presente
    $longueur = strlen($ligne);  // lunghezza riga
    while (substr($ligne, $longueur - 1, 1) == "\n" or substr($ligne, $longueur - 1, 1) == "\r") {
      $ligne = substr($ligne, 0, $longueur - 1);
      $longueur--;
    }
    // fine - si restituisce la riga
    return($ligne);
  }
}

    11.3. Il livello [dao]

    Qui ci interessiamo al livello [1] della nostra applicazione:

    11.3.1. L’interfaccia [InterfaceDao]

    L’interfaccia del livello [dao] sarà la seguente [InterfaceDao.php]:

    
<?php

// spazio dei nomi
namespace Application;

interface InterfaceDao {

  // lettura dei dati dei contribuenti
  public function getTaxPayersData(string $taxPayersFilename, string $errorsFilename): array;

  // lettura dei dati dell'amministrazione fiscale (scaglioni d'imposta)
  public function getTaxAdminData(): TaxAdminData;

  // registrazione dei risultati
  public function saveResults(string $resultsFilename, array $taxPayersData): void;
}

    Commenti

    • le specifiche sono le seguenti:
      • i dati dei contribuenti sono contenuti in un file di testo;
      • i risultati del calcolo delle imposte vengono salvati in un file di testo;
      • gli eventuali errori vengono salvati in un file di testo;
      • non si sa in quale formato siano disponibili i dati dell'amministrazione fiscale. Per ogni nuovo formato, l'interfaccia [InterfaceDao] dovrà essere implementata da una nuova classe;
      • i metodi dell’interfaccia che incontrano un errore irreversibile durante l’accesso ai dati devono generare un’eccezione di tipo [ExceptionImpots];
    • riga 9: il metodo che consente di ottenere i dati del contribuente [statut marital, nombre d’enfants, salaire annuel];
      • il primo parametro è il nome del file di testo in cui si trovano questi dati;
      • il secondo parametro è il nome del file di testo in cui salvare gli eventuali errori riscontrati;
    • riga 12: il metodo che consente di ottenere i dati dall’amministrazione fiscale. Qui non gli viene passato alcun parametro poiché non si sa come siano memorizzati;
    • riga 15: il metodo che consente di salvare i risultati del calcolo dell’imposta in un file di testo il cui nome viene passato come parametro;

    Quando si scrive l’interfaccia [InterfaceDao], si sa che ci saranno diversi modi di scrivere il metodo [getTaxAdminData] a seconda di come saranno memorizzati i dati dell’amministrazione fiscale. L’interfaccia [InterfaceDao] sarà quindi implementata da diverse classi, ciascuna delle quali si occuperà di una specifica modalità di archiviazione di tali dati (tabelle, file di testo, database, servizio web). Queste classi derivate avranno tuttavia un codice comune, ovvero quello relativo all’implementazione dei metodi [getTaxPayersData, saveResults]. È noto che questo caso d’uso può essere implementato in due modi (cfr. paragrafo link):

    1. si crea una classe astratta C che raggruppa il codice comune alle classi derivate. La classe C implementa l’interfaccia I, ma alcuni metodi che devono essere dichiarati nelle classi derivate sono dichiarati astratti nella classe C e quindi la classe C è essa stessa astratta. Si creano quindi le classi C1 e C2 derivate da C, che implementano ciascuna a modo proprio i metodi non definiti (astratti) della loro classe padre C;
    2. si crea un tratto T quasi identico alla classe astratta C della soluzione precedente. Questo tratto non implementa l’interfaccia I poiché sintatticamente non è in grado di farlo. Si creano quindi le classi C1 e C2 che implementano l’interfaccia I e utilizzano il tratto T. A queste classi non resta che implementare i metodi dell’interfaccia I non implementati dal tratto T che importano;

    Per l’esempio, useremo qui un tratto [TraitDao].

    11.3.2. Il tratto [TraitDao]

    Il codice del tratto [TraitDao] è il seguente [TraitDao.php]:

    
<?php

// spazio dei nomi
namespace Application;

trait TraitDao {

  // lettura dei dati dei contribuenti
  public function getTaxPayersData(string $taxPayersFilename, string $errorsFilename): array {
    // tabella dei dati dei contribuenti
    $taxPayersData = [];
    // tabella degli errori
    $errors = [];
    // possono verificarsi numerosi errori durante la gestione dei file
    try {
      // lettura dei dati utente
      // ogni riga ha il formato: stato civile, numero di figli, stipendio annuo
      $taxPayersFile = fopen($taxPayersFilename, "r");
      if (!$taxPayersFile) {
        throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$taxPayersFilename]", 12);
      }
      // si elabora la riga corrente del file dei dati utente
      // che ha il formato: stato civile, numero di figli, stipendio annuo
      $num = 1;         // numero della riga corrente
      $nbErreurs = 0;   // numero di errori riscontrati
      while ($ligne = fgets($taxPayersFile, 100)) {
        // si ignorano le righe vuote
        $ligne = trim($ligne);
        if (strlen($ligne) == 0) {
          // riga successiva
          $num++;
          // si torna all'inizio
          continue;
        }
        // si rimuove l'eventuale carattere di fine riga
        $ligne = Utilitaires::cutNewLineChar($ligne);
        // si recuperano i 3 campi coniuge:figli:stipendio che formano $ligne
        list($marié, $enfants, $salaire) = explode(",", $ligne);
        // li si verifica
        // lo stato civile deve essere «sì» o «no»
        $marié = trim(strtolower($marié));
        $erreur = ($marié !== "oui" and $marié !== "non");
        if (!$erreur) {
          // il numero di figli deve essere un numero intero
          $enfants = trim($enfants);
          if (!preg_match("/^\d+$/", $enfants)) {
            $erreur = TRUE;
          } else {
            $enfants = (int) $enfants;
          }
        }
        if (!$erreur) {
          // lo stipendio è un numero intero senza i centesimi di euro
          $salaire = trim($salaire);
          if (!preg_match("/^\d+$/", $salaire)) {
            $erreur = TRUE;
          } else {
            $salaire = (int) $salaire;
          }
        }
        // errore?
        if ($erreur) {
          $errors[] = "la ligne [$num] du fichier [$taxPayersFilename] est erronée";
          $nbErreurs++;
        } else {
          // si salvano le informazioni
          $taxPayersData[] = (new TaxPayerData())->setFromParameters($marié, $enfants, $salaire);
        }
        // riga successiva
        $num++;
      }
      // si è giunti alla fine del file?
      if (!feof($taxPayersFile)) {
        // si è usciti dal ciclo a causa di un errore di lettura
        throw new ExceptionImpots("Erreur lors de la lecture de la ligne n° [$num] du fichier [$taxPayersFilename]");
      } else {
        // si è usciti dal ciclo al raggiungimento del marcatore di fine file
        // si salvano gli errori in un file di testo
        $this->saveString($errorsFilename, implode("\n", $errors));
        // risultato della funzione
        return $taxPayersData;
      }
    } finally {
      // si chiude il file se è aperto
      if ($taxPayersFile) {
        fclose($taxPayersFile);
      }
    }
  }

  // salvataggio dei risultati
  public function saveResults(string $resultsFilename, array $taxPayersData): void {
    // salvataggio della tabella [$taxPayersData] nel file di testo [$resultsFileName]
    // se il file di testo [$resultsFileName] non esiste, viene creato
    $this->saveString($resultsFilename, implode("\n", $taxPayersData));
  }

  // salvataggio dei risultati di una tabella in un file di testo
  private function saveString(string $fileName, string $data): void {
    // salvataggio della tabella [$data] nel file di testo [$fileName]
    // se il file di testo [$fileName] non esiste, viene creato
    if (file_put_contents($fileName, $data) === FALSE) {
      throw new ExceptionImpots("Erreur lors de l'enregistrement de données dans le fichier texte [$fileName]");
    }
  }

}

    Commenti

    • riga 6: qui definiamo un tratto e non una classe;
    • righe 9-89: il metodo [getTaxPayersData] implementa il metodo omonimo dell’interfaccia [InterfaceDao]. Esso recupera da un file di testo denominato [$taxPayersFilename] i dati dei contribuenti [statut marital, nombre d’enfants, salaire annuel]. Li restituisce sotto forma di una tabella [$taxPayersData] composta da elementi di tipo [TaxPayerData] (righe 67, 81);
    • il metodo [getTaxPayersData] è molto simile al metodo [AbstractBaseImpots::executeBatchImpots] descritto nel paragrafo «Collegamento», con le seguenti differenze:
      • il metodo [getTaxPayersData] si limita a recuperare i dati dei contribuenti. Non effettua alcun calcolo dell’imposta. In questo caso, tale funzione spetta al livello [métier];
      • come faceva il metodo [executeBatchImpots], segnala gli errori. In questo caso gli errori vengono prima memorizzati in un array [$errors] (riga 13), array che viene salvato in un file di testo al termine dell’elaborazione (riga 79). A seconda dei casi, può essere vuoto o meno;
      • in caso di errore irreversibile, viene generata un’eccezione di tipo [ExceptionImpots] (righe 20, 75);
    • riga 73: si noti l’elaborazione effettuata all’uscita dal ciclo delle righe 26-71. Infatti, la funzione [fgets] presenta l’inconveniente di impostare il valore booleano FALSE sia quando la lettura delle righe ha raggiunto il marcatore di fine file, sia quando tale lettura non è andata a buon fine a causa di un errore. Per distinguere i due casi, si verifica se si è giunti alla fine del file con la funzione [feof]. Se non si è giunti alla fine del file, significa che si è verificato un errore e quindi si genera un'eccezione;
    • righe 83-88: la funzione [finally] viene eseguita indipendentemente dal fatto che si sia verificata o meno un’eccezione durante l’elaborazione del file;
    • riga 85: se il file è stato aperto, l’«handle» [$taxPayersFile] del file assume il valore booleano TRUE, altrimenti FALSE;
    • righe 99-105: il metodo privato [saveString] utilizzato alla riga 79 per salvare la tabella degli errori in un file di testo;
    • riga 99: il metodo [saveString] accetta due parametri:
      • [string $filename], che è il nome del file di testo utilizzato per salvare i dati;
      • [string $data], che è la stringa da salvare nel file di testo. Questa stringa sarà costituita da una serie di righe terminate dal carattere di fine riga \n;
    • riga 102: la funzione PHP [file_puts_contents] salva una stringa di caratteri in un file di testo. Si occupa di aprire il file, di scriverci la stringa e di chiudere il file. Restituisce il valore booleano FALSE se si è verificato un errore;
    • riga 103: se si verifica un errore, viene generata un’eccezione;
    • righe 92-96: implementazione del metodo [saveResults] dell’interfaccia [InterfaceDao]. Si utilizza nuovamente il metodo privato [saveString]. Qui il secondo parametro di [saveString] è una stringa costruita a partire dall’array [$taxPayersData], i cui elementi sono di tipo [TaxPayerData]. Ci si può chiedere quale sarà il risultato dell’operazione: 
    
implode("\n", $taxPayersData)

    Nella classe [TaxPayerData] (paragrafo «link») abbiamo definito il seguente metodo [__toString]:

    
public function __toString() {
    // stringa JSON dell'oggetto
    return \json_encode(\get_object_vars($this), JSON_UNESCAPED_UNICODE);
  }

    L’operazione

    
implode("\n", $taxPayersData)

    concatenerà ogni elemento dell’array [$taxPayersData], trasformato in stringa di caratteri dal suo metodo [__toString], con il carattere di fine riga \n. Il risultato sarà una stringa di caratteri della forma:

    json1\njson2\n…

    L’interfaccia del livello [métier] sarà la seguente:

namespace Application;

  // calcolo delle imposte di un contribuente

    Commenti

    • riga 9: l’interfaccia [InterfaceMétier] è in grado di calcolare l’importo dell’imposta di un contribuente privato, purché le vengano fornite le seguenti informazioni: stato civile, numero di figli, stipendio annuo. Il metodo [calculerImpot] non utilizza il livello [dao], pertanto non genera eccezioni;
    • riga 9: l’interfaccia [InterfaceMétier] è in grado di calcolare l’importo dell’imposta anche per un insieme di contribuenti i cui dati sono raccolti nel file di testo denominato [$taxPayersFileName]. È quindi possibile che le eccezioni vengano propagate dal livello [dao] senza essere intercettate dal metodo [executeBatchImpots]: quest’ultimo le lascerà propagare allo script principale. Gli errori non fatali vengono registrati nel file di testo denominato [$errorsFileName];
    • riga 9: il metodo [calculerImpot] è un metodo puramente [métier]. Non si preoccupa della provenienza dei dati che utilizza;
    • riga 12: il metodo [executeBatchImpots] si rivolgerà al livello [dao] per leggere e scrivere dati nei file di testo. Chiamerà ripetutamente il metodo di business [calculerImpot];

public function calculerImpot(string $marié, int $enfants, int $salaire): array {
    // $marié: sì, no
    // $enfants: numero di figli
    // $salaire: stipendio annuo
    // $this->taxAdminData: dati dell'amministrazione fiscale
    //
    // si verifica la presenza dei dati dell'amministrazione fiscale
    if ($this->taxAdminData === NULL) {
      $this->taxAdminData = $this->getTaxAdminData();
    }
    // calcolo dell’imposta con figli
    $result1 = $this->calculerImpot2($marié, $enfants, $salaire);
    $impot1 = $result1["impôt"];
    // calcolo dell'imposta senza figli
    if ($enfants != 0) {
      $result2 = $this->calculerImpot2($marié, 0, $salaire);
      $impot2 = $result2["impôt"];
      // applicazione del limite massimo del quoziente familiare
      $plafonDemiPart = $this->taxAdminData->getPlafondQfDemiPart();
      if ($enfants < 3) {
        // $PLAFOND_QF_DEMI_PART euro per i primi 2 figli
        $impot2 = $impot2 - $enfants * $plafonDemiPart;
      } else {
        // $PLAFOND_QF_DEMI_PART euro per i primi 2 figli, il doppio per i successivi
        $impot2 = $impot2 - 2 * $plafonDemiPart - ($enfants - 2) * 2 * $plafonDemiPart;
      }
    } else {
      $impot2 = $impot1;
      $result2 = $result1;
    }
    // si applica l’imposta più elevata
    if ($impot1 > $impot2) {
      $impot = $impot1;
      $taux = $result1["taux"];
      $surcôte = $result1["surcôte"];
    } else {
      $surcôte = $impot2 - $impot1 + $result2["surcôte"];
      $impot = $impot2;
      $taux = $result2["taux"];
    }
    // calcolo di un'eventuale riduzione
    $décôte = $this->getDecôte($marié, $salaire, $impot);
    $impot -= $décôte;
    // calcolo di un'eventuale riduzione delle imposte
    $réduction = $this->getRéduction($marié, $salaire, $enfants, $impot);
    $impot -= $réduction;
    // risultato
    return ["impôt" => floor($impot), "surcôte" => $surcôte, "décôte" => $décôte, "réduction" => $réduction, "taux" => $taux];

    Per eseguire questa classe di test, si procede come segue:

    • in [1-2], si esegue il test;
    • [3]: la finestra dei risultati dei test;
    • [4]: la classe di test eseguita;
    • [5]: i risultati. In questo caso l’unico metodo di test è stato superato;
    • [6]: quando il test fallisce o, più frequentemente, quando non è stato eseguito alcun test, è necessario consultare la finestra [6]. Nella maggior parte dei casi, è il caricamento dell’ambiente di test ad aver fallito e quindi non è stato possibile eseguire alcun test.
